# adeldaaboul.github.io

Root of Dr. Adel Daaboul's GitHub Pages address. It holds no content of its own; it only sends visitors to the course site:

- `index.html`: `adeldaaboul.github.io` goes to [adeldaaboul.github.io/EENG250](https://adeldaaboul.github.io/EENG250/).
- `404.html`: GitHub Pages addresses are case-sensitive, so `/eeng250`, `/Eeng250/topics` and similar land here and are forwarded to the right page under `/EENG250/`.
- `robots.txt`: points search engines to the course site's sitemap. (Only a `robots.txt` at the root of the address is read, which is why it lives here.)

The course site itself is in the [EENG250](https://github.com/adeldaaboul/EENG250) repository.
